# Install

DipperPDF runs on macOS 14 or later, on Apple silicon and Intel Macs. You do not need an account or an internet connection to use the tools after installing.

## Download and install

1. [Download DipperPDF.dmg](https://github.com/nshntarora/dipperpdf/releases/latest/download/DipperPDF.dmg) from the official GitHub releases.
2. Open the disk image in Finder.
3. Drag **DipperPDF.app** onto the **Applications** shortcut.
4. Eject the disk image and open DipperPDF from Applications.

[Release notes](https://github.com/nshntarora/dipperpdf/releases) describe the version and its signing status. If the download is unavailable, check whether a release containing the DMG has been published.

## If macOS blocks the app

An ad hoc signed release is not notarized and may be blocked by macOS. Check the release notes and confirm that you downloaded it from the official repository before allowing it to open.

After trying to launch the app, open **System Settings → Privacy & Security**. If macOS offers **Open Anyway** for DipperPDF, choose it and confirm the launch. Do not bypass a warning that says the app will damage your computer; download a fresh official copy and report the warning.

## Update or uninstall

To update, quit DipperPDF, download the latest disk image, and replace the app in Applications. To uninstall, quit it and move DipperPDF from Applications to the Trash. PDFs you saved are separate files and remain where you put them.
