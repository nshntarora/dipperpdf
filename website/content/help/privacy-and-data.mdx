# Privacy & data

DipperPDF's native app processes your documents locally. It does not use external PDF services, accounts, analytics, or network access.

## Your documents

You choose files through the native file picker or by dropping them into the app. DipperPDF loads a snapshot into memory for processing. Your original stays unchanged; you choose where to save the output.

Saved results remain wherever you put them. If you save into a folder synchronized by iCloud or another service, that service may upload the output according to its own settings. DipperPDF does not upload it.

## Passwords and unlocked copies

[Unlock PDF](/docs/unlock-pdf) uses the password you enter to open and check the document locally. It saves an unencrypted copy; your source remains encrypted. The unlocked output no longer has the original password protection.

## The website

The website is separate from the native app and does not accept PDF uploads. Its deployment can enable PostHog analytics for website page views and download clicks. That website setting does not add tracking to the Mac app or send it your PDFs.

## Before sharing a result

Review the content and destination of saved files. [Crop PDF](/docs/crop-pdf) hides content without deleting it, [Edit PDF Metadata](/docs/edit-pdf-metadata) changes only four document fields, and [Remove Annotations](/docs/remove-annotations) clears supported review markup. These tools do not provide complete redaction or sanitization.

You can [read the source code](https://github.com/nshntarora/dipperpdf) to inspect the app's file access and processing behavior.
