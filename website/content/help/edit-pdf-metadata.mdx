# Edit PDF Metadata

Update the details used to describe a PDF. These fields are document metadata, separate from the visible words on its pages.

## Edit and save

1. Choose **Edit PDF Metadata** and open your PDF.
2. Edit **Title**, **Author**, **Subject**, and **Keywords**.
3. Separate keywords with commas. Leave a field empty to remove that detail.
4. Click **Save PDF Copy…** and save a separate file.

Changing the title does not rename the source file or change a heading printed on a page. Choose the output filename in the save dialog.

## Privacy limits

Clearing these four fields does not remove personal information from the pages, annotations, or other embedded data. Do not treat it as a complete sanitization step.

Use [Remove Annotations](/docs/remove-annotations) to clear review markup, or [Extract Text](/docs/extract-text) to inspect available selectable text. Always review a document before sharing it.
