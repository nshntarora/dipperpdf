# Getting started

Make your first result with **Compress PDF**, then use the same choose, configure, prepare, review, and save pattern for the other tools.

<DocsTableOfContents entries={toc} />

## Open a PDF

1. [Install DipperPDF](/docs/install) and open it.
2. Choose **Compress PDF** in the app sidebar.
3. Drop a PDF into the file area, or click the area to choose a file from Finder. **Command+O** also opens the file chooser.
4. Wait for the filename and page count to appear.

Most tools accept one PDF at a time. [Merge PDFs](/docs/merge-pdfs) accepts multiple files; [Compare PDF](/docs/compare-pdf) takes an original and a revised PDF. Use **Replace PDF…** to change a single input or **Add PDFs…** to add inputs in a multiple-file tool. Encrypted PDFs must go through [Unlock PDF](/docs/unlock-pdf) first, even if they open without asking for a password.

## Make and save a result

1. Choose **Balanced** compression.
2. Click **Compress PDF** or press **Command+Return** and wait for the size comparison and **Result ready**.
3. Review the output preview. Use its left and right arrows to inspect other pages.
4. Click **Save PDF…** or press **Command+S**, choose a name and location different from the source, and save.
5. Click **Show in Finder** to locate the saved copy, then open it to check the pages and image quality before sharing it.

Your source stays unchanged. DipperPDF prevents saving over the imported source, including through an aliasing file path. Choose a fresh filename for your result.

Every tool prepares a result before saving. Preparation does not write files or open a save dialog. Once a result is ready, the preparation button says **Prepare Again**. Numbering, watermark, and crop diagrams are schematic; the output preview shows the prepared PDF.

[Split PDF](/docs/split-pdf) lets you review each output before **Save PDFs…** asks for a folder and creates a new subfolder. [Extract Text](/docs/extract-text) shows selectable text and uses **Save Text…**. Other tools use **Save PDF…**.

If a PDF preview fails, click **Retry preview**; the prepared result remains available. Cancelling a save dialog or encountering a save error also keeps the result so you can try saving again. While processing, click **Cancel** or press **Escape** to request cancellation; it can take time for the current processing step to finish.

## Work with pages

[Rotate PDF](/docs/rotate-pdf), [Remove Pages](/docs/remove-pages), and [Extract Pages](/docs/extract-pages) use thumbnails:

- Click a page to select it.
- Command-click to add or toggle pages.
- Shift-click to select a range.
- Enter ranges such as `1–3, 5` in **Page numbers**, then click **Apply** or press Return. Invalid input leaves your selection unchanged.
- Use **Select All** or **Command+A** to select every page when a selection tool is active. While editing **Page numbers**, **Command+A** selects the field's text.
- Use **Clear** to clear the selection.

Page-range controls in other tools use **From** and **To** for a consecutive range. All page selections use the PDF's page positions, beginning with 1. Printed page numbers on a document may differ.

## Continue with another tool

Save the result, choose your next tool, and import that saved copy. For example, [merge documents](/docs/merge-pdfs), save the merged PDF, then [add page numbers](/docs/add-page-numbers).

Changing input or processing settings can clear a prepared result; prepare it again before saving. Let a job finish or cancel it before making changes. Switching tools cancels work in the tool you leave.

Review important outputs in a PDF viewer. Rewriting a PDF can invalidate digital signatures or alter bookmarks, tags, forms, and other advanced features.
