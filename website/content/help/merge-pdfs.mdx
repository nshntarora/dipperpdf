# Merge PDFs

Combine two or more PDFs into one file. Files appear in the order shown in the list; pages within each file keep their original order.

## Merge your documents

1. Choose **Merge PDFs** and drop multiple PDFs into the file area, or click it to select them.
2. Use **Add more PDFs** to include other documents.
3. Drag rows into the order you want. You can also right-click a row and choose **Move Up** or **Move Down**.
4. Remove unwanted files with the minus button or the row's **Remove** command.
5. Check the file and page totals, then click **Merge PDFs**.
6. Click **Save PDF…** and save the merged document separately.

For example, placing a two-page cover before a five-page report makes a seven-page PDF with the cover first. At least two files are required to enable Merge PDFs.

## What to check

The list controls whole-file order; it does not reorder individual pages within a file. Use [Extract Pages](/docs/extract-pages) or [Split PDF](/docs/split-pdf) first if you need smaller pieces.

Inputs stay unchanged. Review the result if your documents contain forms, bookmarks, accessibility tags, or digital signatures; these advanced features may change when PDFs are rewritten.

Encrypted inputs need [Unlock PDF](/docs/unlock-pdf) before merging.
